# Portfolio Manager agent

A Research ötleteit a portfólió ismeretében validálja és challenge-eli: előbb a portfólió-illeszkedés (kockázati bucket, ugyanaz a fogadás, cash), utána a teljes kutatás; BUY saját javaslattal (célár, conviction) vagy REJECT. A szabálykaput és a méretezést a runtime alkalmazza. Időzített review-ban a Researchtől kér újraértékelést, és tart / csökkent / zár. IBKR-hez csak olvasási joga van.

Leíró: [`agent.yaml`](agent.yaml). Szerepleírás: [`README.md`](../../README.md#szervezeti-modell).
