# Research agent (Market & Sentiment és Research, egyben verifier)

Egy agent, két funkcióval (Mihály, 2026-10-26).

- **Market & Sentiment:** időzítetten (09:00) figyeli a híreket, indexeket, indikátorokat; piaci összképet, domináns narratívát és legfeljebb 3 befektetési ötletet állít elő.
- **Research:** megtámadja az ötleteket (buy / pass javaslat célárral a PM-nek), a PM kérésére újraértékeli a nyitott pozíciókat, és tanulságot ír a lezárt pozíciókból a központi tudásbázisba (a runtime írja be).

Leíró: [`agent.yaml`](agent.yaml). Szerepleírás: [`docs/ORG.md`](../../docs/ORG.md#research--analyst-egyben-a-verifier).
